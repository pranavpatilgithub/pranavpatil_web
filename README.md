# Portfolio

A dark-first personal site for students and developers who want somewhere to put
their projects and papers. Built with the Next.js App Router, Tailwind v4 and no
other runtime dependencies.

Every piece of content lives in a single file, so you can make this yours
without opening a component.

---

## Features

- **Dark by default**, with a light theme toggle that persists and no flash on reload
- **Case-study pages** for each project, generated from data at build time
- **Research section** with an in-browser PDF viewer, a download link and copyable BibTeX
- **Motion that responds to you** — a lerped cursor ring, hover rows with a
  cursor-following preview, scroll reveals and a progress hairline
- **Static output**, so it deploys anywhere that serves files
- Respects `prefers-reduced-motion`, keyboard focus is visible throughout

---

## Stack

| | |
| --- | --- |
| Framework | Next.js 15 (App Router) |
| UI | React 19 |
| Styling | Tailwind CSS v4 |
| Language | TypeScript |
| Fonts | `next/font/google`, self-hosted at build time |

No animation library, no component library, no CMS.
